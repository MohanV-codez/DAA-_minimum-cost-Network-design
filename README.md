# DAA-_minimum-cost-Network-design
# Minimum Cost Network Design

A Python mini project that designs the **cheapest possible network** connecting all buildings of a campus, and then makes it **fault tolerant** against single cable failures.

Buildings are modelled as nodes and possible cable links as weighted edges. The project finds the Minimum Spanning Tree (MST) using **Kruskal's** and **Prim's** algorithms, adds redundant links so no single cable failure can disconnect the network, and compares the algorithms on graphs of up to 5,000 nodes.

![Network result](network_result.png)

*Left to right: all possible links, the minimum spanning tree, and the MST with redundant links.*

---

## Features

- Kruskal's algorithm with a Union-Find (path compression and union by rank)
- Prim's algorithm with a binary heap (priority queue)
- Automatic verification of both results against NetworkX
- Greedy fault-tolerance step that removes every single point of failure
- Network diagrams drawn with Matplotlib
- Scalability benchmark on random graphs (10, 100, 1,000 and 5,000 nodes)
- Easy to adapt: change two lists to model your own campus, office or village

## Sample Results

Costs are in thousands of rupees for a 9-building campus with 15 possible links.

| Design | Links | Total cost |
|---|---|---|
| All possible links | 15 | 231 |
| Minimum spanning tree | 8 | **102** (55.8% cheaper) |
| MST + redundancy | 11 | 156 (still 32.5% cheaper than all links) |

The MST has no backup path, so any single cable failure would split the campus. The redundancy step adds three links (Admin–Auditorium, Library–ECE Block, Library–Hostel) and leaves **0 single points of failure**.

## Use Your Own Network

Edit the two lists at the top of `min_cost_network.py`:

```python
BUILDINGS = {
    "Server Room": (5, 5),   # name: (x, y) position for drawing
    "Library": (8, 8),
    # ...
}

POSSIBLE_LINKS = [
    ("Server Room", "Library", 14),   # (building A, building B, cost)
    # ...
]
```

The graph must be connected, otherwise no network can reach every building.

## How It Works

1. **Graph model:** buildings are vertices, candidate cables are weighted edges.
2. **Kruskal:** sort edges by cost and add each one unless it creates a cycle (checked with Union-Find). Time complexity O(E log E).
3. **Prim:** grow one tree from a start node, always taking the cheapest edge that leaves it. Time complexity O(E log V).
4. **Redundancy:** repeatedly add the cheapest unused link that reduces the number of bridges (edges whose failure disconnects the network) until none remain.

Finding the cheapest possible fault-tolerant network is NP-hard, so step 4 is a greedy heuristic. It always gives a valid design, but not necessarily the cheapest one.
